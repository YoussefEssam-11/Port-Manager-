# 🔍 Port Scanner & Security Assessment Tool

A professional, multi-threaded port scanner with service detection, risk assessment, and automated security recommendations. Built for penetration testing and network security assessments.

## 📌 Features

| Feature | Description |
|---------|-------------|
| 🚀 Fast Scanning | Multi-threaded - scans 1,000+ ports per second |
| 🔍 Service Detection | Identifies 50+ services (SSH, HTTP, MySQL, RDP, FTP, etc.) |
| 🎯 TCP Handshake | Full SYN/SYN-ACK/RST analysis |
| 📊 Risk Assessment | CVSS-based scoring (Critical/High/Medium/Low) |
| 🛡️ Firewall Rules | Auto-generates iptables (Linux) and netsh (Windows) commands |
| 📄 Professional Reports | Export to HTML, JSON, or TXT format |

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Python 3.x | Core programming language |
| Socket Programming | TCP/IP connection handling |
| Threading | Concurrent port scanning for speed |
| Tkinter | Graphical user interface |
| Socket & Struct | Raw packet handling for SYN scans |
